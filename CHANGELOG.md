# Changelog

## 0.3.0

- Prepare a public Apache-2.0 source release with independent deployment documentation, contribution policy, governance and pinned CI actions.
- Add supported operator workflows for encrypted recovery custody and provider credential provisioning.
- Add a bounded provider broker. Applications receive permitted results; upstream API keys remain under authority custody and OpenBao Transit encryption.
- Add independent Netlify examples for NASA near-Earth objects, Charleston EV charging infrastructure, and a combined science digest. Each uses a fixed OpenAI synthesis operation with a durable hourly paid-operation claim.
- Ship disabled public defaults and versioned example archives with a bundled Node SDK.

PAP credentials renew automatically. Automated replacement of a provider's static API key depends on that provider offering issuance and revocation APIs. This release does not claim automatic rotation of every vendor key, horizontal authority coordination, multi-region high availability or a completed independent security audit.

## 0.2.2

Operator delivery preceding the public source release. Added static OpenBao auto-seal integration, separate Netlify seal custody, and pause and cold-boot recovery acceptance tooling. Operational receipts are deployment-specific and are not public defaults.
